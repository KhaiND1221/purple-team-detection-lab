# Reports

- [`ir-report-template.md`](ir-report-template.md): incident report template (NIST SP 800-61 structure).
- `attack-navigator-layer.json`: generated by `python tools/attack_coverage.py --layer reports/attack-navigator-layer.json`.
  Import it into [ATT&CK Navigator](https://mitre-attack.github.io/attack-navigator/). Score 1 means a rule exists,
  score 2 means the detection was verified in the lab.

Real incident reports from lab runs go in this folder, one file per run, for example `2026-10-IR-001.md`.
Reports contain lab data only; never add employer or customer data.
